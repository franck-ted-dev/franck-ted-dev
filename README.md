# 🚀 Featured Projects

## Recipe Search Engine

Search engine that finds recipes from the ingredients you have, want or want to avoid. Deployed and usable online: a Java backend with no framework (JDK `HttpServer`, JDBC), PostgreSQL, Docker, and a small web interface.

**What it shows**

* Inverted index with the Strategy pattern for the three kinds of ingredient lists
* Data cleaning: free-text ingredients from 790 recipes mapped to a curated list of canonical names
* Complete deployment: Render (Docker), Neon (PostgreSQL), GitHub Pages

🔗 Live demo: https://franck-ted-dev.github.io/recipe-search-engine/
🔗 Code: https://github.com/franck-ted-dev/recipe-search-engine

---

## Football League Analyzer

Java command-line application that loads football match results from a CSV file, validates every record, and computes the league table and team statistics through an interactive text menu.

**What it shows**

* Data validation: invalid records are skipped and logged with a descriptive error message
* League ranking with chained Comparators (points, goal difference, goals scored)
* Records, collections and streams, with a clear split between model, logic, I/O and UI

🔗 https://github.com/franck-ted-dev/football-league-analyzer

---

## Coffee Machine Simulator

Console coffee machine simulator in Java 21, refactored from a programming exercise into a layered application: console UI, controller, services and domain are separated, and the business logic is unit tested.

**What it shows**

* Layered architecture with a clear separation between the console UI and the business logic
* Immutable request and response objects (Java records) and constructor-based dependency injection
* Unit tests with JUnit 5 and coverage analysis with JaCoCo

🔗 https://github.com/franck-ted-dev/coffee-machine-simulator
